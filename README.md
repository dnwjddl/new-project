# Dynamic Video Representation Research Brief

Interactive research proposal for a predictive, anytime Matryoshka video encoder.

The brief covers:

- a flagship predictive-anytime encoder proposal;
- a multi-query amortized hierarchical video representation;
- adaptive recurrent visual latent reasoning for streaming video;
- novelty boundaries against the closest 2025-2026 work;
- falsifiable hypotheses, experiments, baselines, and go/no-go criteria.

The site is a framework-free static page intended for GitHub Pages.

Detailed proposal routes:

- `/1-proposal/`: predictive anytime video encoder;
- `/2-proposal/`: multi-query amortized token tree;
- `/3-proposal/`: query-free streaming visual latent reasoning and the first GPU pilot.

The Proposal 03 pilot code and raw measured result are under `experiments/`.
