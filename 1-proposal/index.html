PROPOSAL 01 · BROAD REPRESENTATION PROBLEM

Dual-Control State–Innovation Video Encoder

하나의 pretrained video encoder를 직접 지정한 hard token budget으로 실행하거나, query 없이 다음 token의 marginal temporal information을 판단해 스스로 멈추게 한다. 모든 실행은 state와 innovation을 함께 보존하는 동일한 gist-first nested representation을 공유한다.

01 · THE PROBLEM

Video에서 “coarse”가 무엇인지 정의하지 않으면 첫 token의 역할도 알 수 없다.

image에서는 layout→object→texture가 자연스러운 해상도 축이다. 그러나 video에서 coarse token이 평균 frame인지, 주행동인지, motion인지, 긴 시간의 요약인지는 서로 다른 주장이다. 먼저 기존 token의 실제 역할을 측정하고, 시간축에 고유한 state–innovation 분해를 학습 목표로 준다.

FAILURE SCENE

64초 중 0.5초의 상태 변화가 질문의 정답을 바꾼다.

appearance는 거의 같지만 컵이 비워지는 순간, 손의 방향 전환, 행동 순서 반전은 temporal QA에 결정적이다.

L1

Pixel fidelity ≠ answer sufficiency

texture를 잘 복원해도 state change와 causal order를 잃을 수 있다.

L2

질문을 미리 사용할 수 없다

query-aware selector와 달리 encoder는 미래의 다양한 downstream task에 재사용되어야 한다.

L3

Post-hoc pruning은 encoder를 싸게 만들지 않는다

dense ViT를 전부 실행한 뒤 token만 줄이면 LLM prefill은 줄지만 vision FLOPs는 그대로다.

L4

앞 token이라고 자동으로 “coarse”해지지 않는다

nested dropout은 prefix validity를 유도하지만, 각 token이 state·motion·order·rare event 중 무엇을 담당하는지 보장하지 않는다.

THE OPEN GAP

“Not coarse-to-fine, but persistence ↔ innovation.” Pixel residual이 아닌 semantic persistence와 innovation을 role-paired nested tokens로 만들고, 각 추가 group의 temporal marginal information을 직접 감독한다. 같은 prefix를 user-specified hard budget과 query-agnostic automatic stopping에서 모두 쓰는 실제 anytime encoder가 핵심 빈틈이다.

04 · METHOD

One nested encoder supports a hard budget and learned temporal stopping.

pretrained causal encoder를 stage로 나누고 첫 stage에서 temporal gist를 만든다. 다음 stage는 앞 prefix가 놓친 state·innovation residual과 실제 utility가 충분할 때만 실행한다. 따라서 output token뿐 아니라 deeper encoder block의 FLOPs도 video별로 달라진다.

낮은 budget에서는 뒤 stage와 residual token group을 실제로 실행하지 않는다. 모든 mode는 동일한 prefix Rₖ={(S₁,I₁),…,(Sₖ,Iₖ)}를 반환하므로 representation은 control 방식과 무관하다.

MODE A · USER-SPECIFIED

Hard budget execution

K = Kuser

사용자가 token 수, latency tier 또는 device profile을 지정한다. encoder는 정확히 K번째 exit까지만 실행해 예측 가능한 FLOPs와 output length를 보장한다.

MODE B · BUDGET-FREE

Marginal information stopping

stop if Δ̂k+1 < λ · ΔCk+1

query 없이 다음 stage가 줄 temporal error와 추가 FLOPs를 비교한다. validation에서 calibration한 λ로 각 video의 최소 충분 prefix를 선택한다.

SHARED INVARIANT

같은 video의 automatic output은 반드시 fixed-budget prefix 중 하나여야 한다. 별도 router representation을 만들지 않아 manual/automatic 결과를 직접 비교할 수 있다.

STANDARD REPA

하나의 hidden state를 하나의 clean teacher feature에 정렬

noisy hidden h → projector → clean feature y

Diffusion representation과 convergence를 개선한다. Budget이 바뀌어도 같은 absolute target을 반복해서 모방한다.

M1

Stage-partitioned pretrained encoder

초기 block은 모든 video가 공유하고, 각 exit 뒤에는 active patch를 nested하게 줄인다. 낮은 budget은 뒤 attention block을 건너뛰므로 vision FLOPs가 실제로 감소한다.

M2

Role-paired residual tokens

각 tier가 state register와 innovation register를 함께 추가한다. k번째 pair는 이전 prefix가 놓친 persistent state, order, transition, rare event만 보충한다.

M3

Marginal utility head

현재 prefix와 early features만 보고 다음 stage가 줄 temporal loss Δ̂와 비용 ΔC를 예측한다. fixed mode는 이 결정을 무시하고, automatic mode만 calibrated stopping을 사용한다.

DUAL-CONTROL TRAINING OBJECTIVE

모든 prefix를 유효하게 만들고, 다음 stage의 실제 temporal gain을 예측한다.

Ltemp(k) = Lstate(k) + Lorder(k) + Lfuture(k)
Δ*k+1 = sg([Ltemp(k) − Ltemp(k+1)]+)
Lgate = SmoothL1(Δ̂k+1, Δ*k+1) + Lcalibration
Ltotal = Σk wk Ltemp(k) + βLmonotonic + γLgate + λE[FLOPs]
IS V-JEPA REQUIRED?

No. 가장 간단한 시작은 full-budget EMA branch를 self-teacher로 쓰는 것이다. V-JEPA는 future-sensitive semantic target을 더할 수 있는 선택사항이다. 외부 teacher 없이도 action·order·future losses에서 계산한 prefix별 error 감소가 gate의 oracle marginal gain이 된다.

05 · NO-SCRATCH RECIPE

Frozen exits에서 시작해 calibrated adaptive compute로 단계적으로 학습한다.

처음부터 backbone 전체와 discrete gate를 함께 학습하면 representation과 routing이 동시에 흔들린다. 먼저 각 prefix의 temporal utility를 만들고, 그 utility를 예측하는 gate를 학습한 뒤, 마지막에만 encoder adapter를 열어 실제 FLOPs–accuracy Pareto를 조정한다.

PHASE A · ORACLE CURVES

Measure every exit

pretrained backbone을 stage로 나누고 모든 prefix에서 action, order, future prediction loss를 측정한다. 이 값이 video별 실제 marginal gain Δ*와 oracle minimum K를 만든다.

PHASE B · FROZEN WARM-UP

Learn gist-first exits

backbone은 freeze하고 role registers, projection heads, nested patch router만 학습한다. mini-batch마다 여러 K를 뽑아 같은 video의 모든 선택된 prefix가 유효하도록 만든다.

PHASE C · GATE DISTILLATION

Predict the next gain

현재 prefix와 early feature에서 Δ̂k+1을 회귀하고 oracle continue/stop label을 distill한다. gate는 validation set에서 expected calibration error와 stopping regret로 보정한다.

PHASE D · JOINT EFFICIENCY

Open adapters, then LoRA

먼저 stage adapter만 열고 마지막에 backbone의 뒤 2–4 block LoRA를 연다. straight-through 또는 soft continue probability로 expected FLOPs penalty를 함께 최적화한다.

01

Shared early pass

한 번의 early-stage forward로 모든 budget이 공유할 causal patch feature를 만든다.

02

Full path target

no-grad EMA full path 또는 optional frozen teacher에서 semantic target을 얻는다.

03

Random prefixes

K를 최소 두 개 sampling하고 state–innovation role loss와 task loss를 각 exit에 적용한다.

04

Oracle gain

인접 exit의 temporal loss 감소를 stop-gradient target Δ*로 계산한다.

05

Cost-aware update

gate calibration, monotonicity, expected FLOPs를 합쳐 adapter·router를 업데이트한다.

RECOMMENDED FIRST MODEL

Pretrained causal video backbone + four exits + role-paired cross-attention registers + scalar marginal head. Phase B까지 backbone을 freeze하고, Phase D에서 adapter를 먼저 연다. 이 구성이 성공한 뒤에만 last-block LoRA를 사용하면 scratch training 없이 representation gain과 compute gain을 분리해 분석할 수 있다.

07 · KILL TESTS

아래 셋 중 하나가 실패하면 role-aware claim을 즉시 줄인다.

NO-GO 01

Token은 줄지만 encoder FLOPs는 그대로다

초기 dense stage가 전체 계산을 지배하거나 conditional block의 실제 latency가 줄지 않으면 efficient encoder가 아니라 output compressor로 claim을 낮춘다.

NO-GO 02

Automatic gate가 fixed K를 이기지 못한다

동일 평균 GFLOPs에서 accuracy gain이 없거나 oracle stopping regret가 크면 auto mode를 제거하고 user-controlled anytime encoder만 남긴다.

NO-GO 03

Temporal role이 downstream gain으로 연결되지 않는다

같은 token·FLOPs의 direct distillation과 order·state-change benchmark 차이가 없으면 state–innovation objective의 claim을 축소한다.

08 · 2–3H COMPUTE PLAN

한 configuration을 2–3시간에 끝내려면 proxy는 가볍게, encoder adaptation은 강하게 병렬화해야 한다.

아래는 H100 SXM 80GB, BF16, optimized attention, pre-sharded dataloader를 가정한 초기 scheduler budget이다. A100 80GB만 가능하면 H100 수의 약 1.7배 또는 1.5–2배 wall-clock을 먼저 계획한다. 한 run은 full official split의 한 configuration·한 seed이며 queue 대기시간은 제외한다.

MEASURED CALIBRATION · RTX 3090 / 4090 / A6000

공식 checkpoint와 paper-grade audit 완료. VideoFlexTok K600 encoder는 17-frame clip에서 pre-quantized·quantized latent [1,5,256,6]와 token ID [1,5,256]를 출력한다. RTX 3090 최적 batch는 12였고 0.477 clip/s, peak reserved memory 17.95 GiB였다. 모든 3,568 action stratum을 포함한 deterministic train 16k와 decodable val 9,657개를 8개 GPU로 처리했으며 slowest shard는 train 52.4분, val 43.6분이었다. 3-seed concatenated·fixed-dimension probe 전체 분석은 RTX 4090 한 장에서 8분 23초였다.

FULL-SPLIT RESULT · EK100 · 3 SEEDS

통상적인 action probe는 시간 순서에 거의 둔감했다. ViCLIP-L/14 frozen feature의 ordered action top-1은 15.02%였지만 reverse는 14.60%(-0.42pp), shuffle은 14.62%(-0.40pp)였다. 반면 한 frame만 반복한 single 조건은 10.24%(-4.78pp)까지 하락했다. 즉 이 probe는 appearance·object 제거에는 반응하지만 순서 교란은 거의 구별하지 못한다. 공식 train 67,217개와 val 9,668개를 사용했고, 손상된 원본 video packet 때문에 train 1개와 val 9개 segment만 동일 규칙으로 제외했다.

PILOT VERDICT

기존 순서는 understanding의 successively refinable coarse-to-fine이 아니다. Quantized concatenated probe에서 첫 8-token prefix의 action top-1은 4.10%로 256-token의 3.35%보다 높았다. 입력 차원을 모두 18로 맞춘 통제에서도 8-token prefix는 2.77±0.14%, 256-token은 1.83±0.09%였고, 첫 block은 2.69%로 이후 block의 1.15–1.63%보다 강했다. 첫 block은 reverse에도 더 민감해 action과 order 정보가 앞쪽에 섞여 몰려 있었다. 따라서 우리의 목표는 “앞=coarse”를 반복하는 것이 아니라 stable state token과 order-sensitive innovation token을 명시적으로 분리하고, 추가 group이 남은 semantic residual을 단조롭게 줄이게 만드는 것이다.
