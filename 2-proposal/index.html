PROPOSAL 02 · REUSABLE PERCEPTION PROBLEM

Multi-query Amortized Token Tree

한 영상을 여러 질문이 반복해서 사용할 때, 매번 같은 evidence를 다시 찾고 계산하지 않는다. 질문 없이 만든 hierarchy와 이전 질문이 이미 연 branch를 persistent state로 공유해 query당 한계 비용을 낮춘다.

ONE-SENTENCE CLAIM

query-agnostic video tree를 한 번 만들고 각 질문이 연 evidence branch를 누적 cache하면, 질문 수가 늘어날수록 정확도를 유지하면서 평균 encoder·retrieval·prefill 비용을 체계적으로 낮출 수 있다.

01 · THE PROBLEM

현재 방법은 같은 영상을 재사용해도 각 query를 거의 독립적인 사건으로 취급한다.

실제 video agent와 분석 도구에서는 한 영상에 요약, 원인, 특정 객체, 후속 확인 질문이 연속해서 들어온다. Q₁에서 찾은 증거가 Q₂의 시작점이 되지 못하면 query-aware selection의 비용이 계속 반복된다.

REPEATED WORK

질문은 바뀌지만, 필요한 event와 이미 본 branch는 자주 겹친다.

Q₁ “컵을 누가 옮겼나?” → Q₂ “옮기기 전에 컵 안에는 무엇이 있었나?” → Q₃ “그 뒤 컵은 어디에 놓였나?”

L1

Per-query hierarchy construction

query마다 tree나 ranking을 새로 만들면 같은 evidence discovery가 반복된다.

L2

Flat cache는 semantic expansion을 모른다

KV나 dense tokens를 보관해도 parent summary에서 필요한 child detail만 점진적으로 여는 구조가 없다.

L3

Reuse가 학습 목표가 아니다

개별 query 정확도와 latency를 최적화할 뿐 query sequence 전체의 incremental cost를 직접 줄이지 않는다.

L4

평가 단위가 Q=1에 머문다

질문 수, 관련성, 순서가 바뀔 때 total cost와 cache growth가 어떻게 변하는지 보고되지 않는 경우가 많다.

02 · PRIOR-WORK BOUNDARY

Cache reuse, query routing, hierarchy는 이미 있다. 남은 것은 이 셋의 sequence-level 학습이다.

WorkWhat it already solvesWhat remains for this proposal

VideoTreeCVPR 2025

query를 사용해 long video의 hierarchical tree를 만들고 coarse-to-fine으로 관련 node를 탐색한다.

여러 다른 query가 하나의 query-agnostic tree와 과거 expansion을 누적 재사용하는 목적이 아니다.

QTS+ / VideoRouterarXiv 2025–2026

각 query의 난이도와 관련성에 따라 visual token·frame budget을 동적으로 선택한다.

Qᵢ가 수행한 evidence discovery가 Qᵢ₊₁의 비용을 낮추도록 sequence 전체를 최적화하지 않는다.

SparseVILA / VLCachearXiv 2025

multi-turn fidelity를 위한 visual cache 보존과 동일 multimodal input의 encoder·KV 재사용을 제공한다.

semantic parent-child residual과 query-driven cumulative branch expansion을 학습하지 않는다.

MuKVarXiv 2026

patch·frame·segment 수준의 multi-grained KV와 semi-hierarchical retrieval을 사용한다.

distinct query sequence에 대해 열린 branch를 persistent하게 확장하며 총 incremental cost를 최적화하는 설정이 아니다.

MECarXiv 2026-08

한 query에서 sparse index와 evidence-to-context ranking을 만들어 여러 frame budget prefix에 재사용한다.

budget 간 prefix reuse는 해결하지만 서로 다른 query 간의 cumulative evidence reuse는 다루지 않는다.

THE OPEN GAP

여러 query가 공유하는 representation을 정적으로 cache하는 것을 넘어, 질문이 올 때마다 필요한 semantic branch만 확장하고 그 계산을 영구히 남기도록 query sequence의 총 한계 비용을 직접 학습하는 문제가 열려 있다.

03 · METHOD

Encode once, open evidence once, reuse it for every later question.

initial state는 모든 query가 공유하는 global gist와 event index다. query router는 top-down으로 필요한 branch와 depth를 고르고, 새로 계산·회수한 residual은 cumulative cache에 합쳐진다.

04 · TRAINING

한 질문씩 섞지 말고 query workload 자체를 sample한다.

PHASE A · TREE

Query-free hierarchy

scene boundary와 teacher residual로 global → event → detail node를 만들고 모든 parent가 standalone summary가 되게 한다.

PHASE B · ROUTER

Single-query oracle

answer loss와 evidence localization으로 branch utility를 학습한 뒤 cost-constrained beam routing을 맞춘다.

PHASE C · SEQUENCE

Cache-aware episodes

관련·비관련 query를 섞은 episode에서 이미 열린 node의 reuse credit과 새 node의 incremental penalty를 준다.

PHASE D · POLICY

Bounded cache

메모리 한계에서 gist·rare event·high-reuse branch를 남기는 eviction policy와 order robustness를 학습한다.

05 · EVIDENCE NEEDED

핵심 그림은 Q가 늘수록 내려가는 average marginal cost다.

C1

Multi-query workload formulation

video understanding 효율을 Q=1 latency가 아닌 representation lifecycle cost로 정의한다.

C2

Semantic cumulative expansion

이전 query의 evidence discovery와 branch refinement를 다음 query의 persistent computation으로 바꾼다.

C3

Cache-aware sequence training

query order와 relatedness를 포함해 total incremental cost를 직접 최적화한다.

C4

Lifecycle benchmark protocol

Q=1·5·10·20, cache budget, query diversity별 accuracy–total cost frontier를 제안한다.

06 · KILL TESTS

Reuse라는 말이 실제 비용 감소로 이어지지 않으면 논문은 성립하지 않는다.

NO-GO 01

Q가 늘어도 평균 비용이 평평하다

질문 간 evidence overlap이 부족하거나 cache 조회 비용이 크면 broad interaction claim을 줄이고 특정 workload로 한정한다.

NO-GO 02

Flat cache와 차이가 없다

동일 memory에서 단순 dense token cache/top-k가 같거나 더 좋으면 hierarchy와 residual training의 필요성이 없다.

NO-GO 03

Query order에 과민하다

초기 질문이 cache를 오염시켜 후속 정확도가 떨어지면 immutable gist와 uncertainty-aware eviction을 강제한다.
