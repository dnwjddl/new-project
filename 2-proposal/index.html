PROPOSAL 02 · REUSABLE PERCEPTION PROBLEM

Query-Evolving Video Memory

생물학적 기억은 회상될 때 그대로 읽히지 않고 다시 조직된다. query-agnostic episodic video memory에서 질문이 관련 사건을 활성화하면, 함께 활성화된 evidence를 semantic schema로 reconsolidate한다. 이후 질문은 동일 chunk가 아니어도 공유된 사건·객체·인과 구조를 통해 더 빠르게 기억을 완성한다.

PRIMARY AXISMemory reconsolidation
QUERY SETTINGSequential Q₁…Qᴺ
MAIN METRICFuture-query transfer
ONE-SENTENCE CLAIM

질문이 회상한 visual evidence로 memory structure를 reconsolidate하면, exact chunk overlap이 없는 후속 query도 더 적은 신규 perception으로 정확하게 답할 수 있다.

01 · THE PROBLEM

현재 video memory는 질문으로 기억을 읽지만, 그 경험으로 기억 구조를 배우지는 않는다.

실제 video agent에서는 한 사건을 둘러싼 원인·객체·순서 질문이 연속해서 들어온다. 단순 cache는 같은 chunk가 다시 필요할 때만 이득을 얻는다. 더 중요한 문제는 서로 다른 구간을 묻더라도 이전 회상이 만든 사건 구조가 다음 질문의 pattern completion을 도울 수 있는가이다.

RETRIEVAL SHOULD CHANGE MEMORY

질문은 서로 다른 순간을 묻지만 같은 event schema를 공유할 수 있다.

Q₁ “컵을 누가 옮겼나?” → Q₂ “옮기기 전에 컵 안에는 무엇이 있었나?” → Q₃ “그 뒤 컵은 어디에 놓였나?”

L1

Read-only retrieval

query는 evidence를 가져오지만 어떤 사건들이 함께 활성화됐는지를 visual memory에 다시 쓰지 않는다.

L2

Exact reuse only

token cache는 동일 branch 재사용에는 강하지만 disjoint evidence 사이의 semantic relation을 만들지 않는다.

L3

QA summary ≠ visual reconsolidation

질문과 답을 text로 누적해도 원래 event token의 관계와 retrieval path가 개선되는 것은 아니다.

L4

No retrieval-practice evaluation

이전 질문을 경험한 뒤 held-out query의 정확도와 신규 visual compute가 실제로 개선되는지 거의 측정하지 않는다.

02 · PRIOR-WORK BOUNDARY

Cache, hierarchy, consolidation은 이미 있다. 남은 것은 retrieval-induced visual reconsolidation이다.

WorkWhat it already solvesWhat remains for this proposal

실제로 들어온 query sequence의 회상 결과가 memory를 재구성하고 이후 unseen query에 transfer되는 문제와는 다르다.

THE OPEN GAP

Retrieval-induced video memory reconsolidation. 질문이 함께 활성화한 visual episodes의 관계를 bounded schema memory에 다시 쓰고, exact temporal overlap이 없는 후속 질문에도 그 구조가 pattern completion과 신규 perception 감소로 transfer되는지를 학습·평가하는 빈틈이다.

03 · METHOD

Recall, bind, and reconsolidate: 질문을 받을수록 memory가 의미 구조를 배운다.

raw event tree는 evidence를 보존하는 immutable episodic memory로 둔다. query가 여러 event를 함께 활성화하면 그 co-activation과 temporal relation만 작은 schema memory에 쓴다. 이후 query는 schema로 관련 episode를 pattern-complete하고, 불충분할 때만 새로운 visual evidence를 연다.

Cache는 순차 query에서 latent를 유지하는 구현 요소일 뿐 contribution이 아니다. 핵심은 retrieved evidence를 그대로 쌓지 않고, 검증된 co-activation relation으로 bounded schema를 갱신해 exact-overlap 밖의 query transfer를 만드는 것이다.

M1

Immutable episodic tree

query 없이 만든 event token과 temporal hierarchy가 원본 evidence를 보존한다. generated answer의 오류가 raw memory를 덮어쓰지 못하게 한다.

M2

Co-activation schema slots

한 query에서 함께 retrieval된 event의 객체·행동·순서 relation을 bounded semantic slots와 sparse edges로 압축한다.

M3

Confidence-gated reconsolidation

evidence-grounded retrieval만 schema를 갱신하고, 후속 query는 schema activation과 현재 query를 결합해 필요한 episode를 완성한다.

SEQUENCE OBJECTIVE

현재 답뿐 아니라 reconsolidation 뒤 held-out query의 효율과 정확도를 개선한다.

L = Σᵢ LQA(qᵢ) + λΔCᵢ + βLnext(qᵢ₊₁ | Sᵢ) + γLinterference

04 · TRAINING

Full method 전에 training-free spreading activation으로 가설부터 검증한다.

PHASE A · PHENOMENON

Separate reuse from transfer

same-video query pair를 exact-overlap, disjoint-but-related, unrelated로 나누고 각 집단의 규모와 baseline retrieval difficulty를 측정한다.

PHASE B · UPPER BOUND

Oracle retrieval-practice gain

이전 query의 ground-truth evidence relation만 제공했을 때 held-out query hit@K가 얼마나 오르는지 재서 가능한 transfer의 상한을 구한다.

PHASE C · NO-TRAINING TEST

Spreading activation

과거 retrieval co-activation으로 event graph edge를 만들고 query similarity를 이 graph로 전파한다. parameter update 없이 flat retrieval보다 좋아지는지 본다.

PHASE D · LEARNED UPDATE

Bounded reconsolidation

앞 세 실험이 통과한 뒤에만 schema slots, confidence gate, future-query transfer loss를 학습한다.

05 · MOTIVATION-FIRST EXPERIMENTS

Method 전에 “회상 경험이 다음 질문을 돕는가”부터 세 단계로 확인한다.

E1

Query-pair taxonomy

Ego4D NLQ의 same-video query pairs를 temporal IoU와 semantic relation으로 분류한다. embedding으로 후보를 만들고 human-audited subset으로 검증해, window는 겹치지 않지만 동일 event·entity·causal chain을 공유하는 pair의 비율을 보고한다.

E2

History utility upper bound

첫 query의 answer text 없이 ground-truth visual evidence relation만 memory에 준다. held-out second query의 hit@K와 신규 leaf 수가 개선되면 reconsolidation의 가능한 이득이 존재한다.

E3

Training-free reconsolidation

retrieved leaves의 co-activation graph에 Hebbian-style edge update와 decay만 적용한다. 이는 생물학적 충실성 주장이 아닌 계산적 analogy다. flat CLIP, exact cache, QA-text history, shuffled history와 동일 K에서 비교한다.

THE CRITICAL SLICE

Disjoint-but-related query pairs. Exact temporal overlap이 없어 단순 branch cache는 도움을 주지 못하지만, 같은 event schema를 공유하는 경우다. 이 subset에서 previous-query history가 held-out accuracy를 높이고 new visual evidence를 줄여야 biological reconsolidation claim이 성립한다.

C1

Retrieval-practice formulation

multi-query benefit을 exact token reuse가 아니라 이전 회상 뒤 unseen query의 positive transfer로 정의한다.

C2

Episodic–schema dual memory

immutable visual episodes와 query-induced bounded schema를 분리해 evidence fidelity와 semantic abstraction을 함께 유지한다.

C3

Retrieval-induced reconsolidation

co-activated event relation을 다시 써서 raw overlap이 없는 후속 query의 pattern completion을 돕는다.

C4

Transfer and interference protocol

related·unrelated·shuffled·adversarial history에서 future-query gain, 신규 compute, forgetting과 order robustness를 함께 측정한다.

THE DECISIVE FIGURE

Held-out accuracy and new evidence cost after retrieval practice

06 · KILL TESTS

Exact cache 이상의 semantic transfer가 없으면 reconsolidation 논문은 성립하지 않는다.

NO-GO 01

Disjoint-related pairs가 드물다

실제 workload에서 semantic relation은 대부분 exact temporal overlap으로 설명된다면 reconsolidation 대신 단순 cache 문제로 축소한다.

NO-GO 02

Oracle history도 future query를 돕지 못한다

정답 evidence relation을 줘도 held-out retrieval이 개선되지 않으면 schema transfer 가정 자체를 폐기한다.

NO-GO 03

관련 history가 interference를 만든다

positive transfer보다 잘못된 association과 order sensitivity가 크면 update를 confidence-gated read-only retrieval로 제한한다.

07 · 2–3H COMPUTE PLAN

Motivation 분석은 cached feature로 가볍고, full reader와 learned reconsolidation이 자원의 대부분을 차지한다.

아래는 H100 SXM 80GB, BF16, Ego4D NLQ official split, Q={1,2,4,8,16} workload를 가정한 초기 추정이다. A100 80GB는 H100 수의 약 1.7배를 초기값으로 잡고 5% throughput calibration 후 조정한다. 한 run은 한 configuration·한 seed이며 queue time은 제외한다.

MEASURED CALIBRATION · 8 × RTX 3090 / A6000

실제 자연어 multi-query workload 완료. Ego4D NLQ official train은 13,849 queries, val은 4,554 queries이며 query text가 없는 4개 항목은 명시적으로 제외한다. 4초 query-agnostic leaf cache는 train 157,459개와 val 52,027개다. 각 GPU가 서로 다른 영상을 4-reader로 decode해 FP16 CLIP-L/14 feature를 저장했고 decode 실패는 0건이었다. Slowest shard 기준 train 55.2분, val 20.8분이었으며 full 3-seed·20-epoch router/tree 분석은 A6000 한 장에서 76초였다.

FULL-SPLIT RESULT · EGO4D NLQ · 3 SEEDS

기존 실험은 exact evidence reuse가 실제 질의에 존재함을 확인했다. 1,271 train clips·415 val clips와 usable 13,847/4,552 queries 전체를 사용했다. budget 4에서 Q=8일 때 query당 unique opened leaf는 4.00개에서 3.27개로 줄었다. Uniform tree는 budget 8에서 flat search의 137.5회 대신 47.3회 비교(-65.6%)로 routing했다. 이는 reconsolidation이 아니라 동일 leaf 재사용의 baseline이다.

ACCURACY GAP · THE NEXT METHOD TARGET

14.7% total-cost 수치는 per-query video feature recomputation을 가정한 상대값이라 최신 cache baseline 대비 novelty가 아니다. 더 중요한 결과는 Raw CLIP budget-8 overlap hit가 flat 41.65% 대 uniform tree 31.88%였고, geometry-preserving residual router가 40.79%까지 회복했다는 점이다. 새 motivation 실험은 tree 승리를 가정하지 않고 flat geometry 위에서 exact reuse와 semantic transfer를 먼저 분리한다.

RUN DEFINITION

video feature와 immutable episodic tree는 한 번 만들어 모든 query order·schema budget·retrieval baseline이 공유한다. motivation E1–E3는 cached feature에서 수행하고, learned reconsolidation과 deterministic 7B reader 평가는 seed·query episode별로 분산한다.
