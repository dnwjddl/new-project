PROPOSAL 02 · LITERATURE RESET · 2026-08-11

Online Multi-Query Amortization

같은 영상에 질문이 하나씩 순차적으로 들어오고 미래 질문은 알 수 없다. 이미 열린 visual evidence는 재사용할 수 있지만, 현재 질문을 정확히 답하기 위해 무엇을 새로 계산해야 하는지는 매 turn 달라진다. Proposal 2는 새 token tree를 주장하지 않고, 질문 sequence 전체의 누적 비용을 최소화하는 online evidence-acquisition 문제를 검증한다.

ONE-SENTENCE HYPOTHESIS

미래 질문을 보지 않는 online policy가 query history와 이미 확보한 evidence를 이용해, 독립 query 실행보다 낮은 cumulative visual cost와 offline oracle에 가까운 accuracy를 달성할 수 있는가?

01 · PROPOSAL BOUNDARY

Proposal 1은 영상을 압축하고, Proposal 2는 여러 질문이 그 계산을 어떻게 공유할지 다룬다.

방금 논의한 future-query coverage 학습은 query-agnostic compact representation을 개선하므로 Proposal 1과 겹친다. 특히 MetaCompress가 이미 unknown future query를 위한 prompt-agnostic 학습을 제시했다. Proposal 2는 encoder representation 자체를 contribution으로 삼지 않고 multi-query serving objective로 경계를 옮긴다.

AxisProposal 1 · Adaptive encoderProposal 2 · Multi-query system

Decision input

영상의 semantic-temporal complexity. Language query는 사용하지 않는다.

현재 query, 이전 query history, 이미 확보한 evidence와 남은 memory budget.

Output

영상마다 다른 token budget K(x)와 gist-first nested representation.

각 turn에서 새로 열 evidence와 reuse할 evidence를 결정하는 online action.

Objective

한 영상을 인코딩하는 FLOPs와 task-agnostic temporal information 보존.

Q₁…Qᴺ 전체 accuracy를 유지하면서 발생한 cumulative new visual compute.

Failure mode

복잡한 영상에 token이 부족하거나 쉬운 영상에 token을 낭비한다.

각 질문을 독립적으로 잘 풀어도 sequence 전체에서는 같은 evidence를 반복 계산한다.

IMPORTANT RESET

Adversarial future-query training은 Proposal 2의 중심에서 제외한다. Worst-query loss는 유용한 ablation일 수 있지만 query-agnostic compression 학습이라는 점에서 MetaCompress 및 Proposal 1과 너무 가깝다.

02 · RELATED-WORK MAP

관련 축은 이미 촘촘하다. 무엇이 해결됐는지부터 분리해야 한다.

아래는 2026년 8월까지 직접적으로 Proposal 2를 압박하는 연구들이다. 단순히 tree, cache, multi-turn이라는 단어를 새 contribution으로 사용할 수 없음을 보여준다.

Research axisRepresentative work and solutionImplication for us

Query-conditioned selectionSINGLE QUERY

VideoTree는 query-adaptive hierarchy를 coarse-to-fine 탐색한다. QTS+는 query별 retention budget과 token을 학습한다. VideoRouter는 coverage와 high-resolution evidence 사이를 query별 routing한다. QViC-MF는 question-guided compression에 과거 memory feedback을 넣는다.

Query similarity로 branch·frame·token을 고르는 것 자체에는 novelty가 없다.

Future-query-safe compressionPROMPT AGNOSTIC

MetaCompress는 미래 질문이 unknown인 multi-turn VQA를 직접 문제화하고 prompt-agnostic learnable compression을 제시한다. StreamMem은 generic query tokens로 fixed-size query-agnostic KV memory를 유지한다. ObjectStream은 persistent latent objects와 state change를 bounded memory anchor로 쓴다. MemoryCard는 query 전에 event gist와 representative moments를 self-reading해 retrieval 단위로 만든다.

“미래 질문을 위해 compact representation을 잘 만들자”는 주장은 이미 직접적인 선행 연구가 있다.

Reusable video/KV memoryREPEATED QA

MC-ViT는 과거 activation을 non-parametric memory로 consolidate한다. ReKV는 video encoding과 QA를 분리하고 query-relevant KV를 재사용한다. StreamKV는 semantic segment 단위 retrieval·compression을 결합한다. MuKV는 patch·frame·segment KV를 semi-hierarchical하게 retrieval한다. FlexMem은 compressed visual KV memory를 training-free로 읽고 쓴다. WeaveTime은 uncertainty-triggered past-current cache로 multi-turn streaming QA를 개선한다.

한 번 encode하고 이후 질문에서 KV나 segment를 재사용하는 것도 이미 강한 baseline이다.

Semantic and agent memoryMULTI-TURN

M3-Agent는 entity-centric episodic·semantic memory와 multi-turn reasoning을 학습한다. WorldMM은 episodic·semantic·visual memory를 선택하며 충분할 때까지 retrieval한다. OASIS는 intent-driven hierarchical event retrieval과 5-query SQA를 평가한다. PMMC는 미래 질문 후보와 evidence program을 consolidation 시점에 미리 compile한다.

Semantic memory, QA history, future-query anticipation, iterative sufficiency도 독립 novelty가 아니다.

Multi-turn learning and evaluationTRAIN / BENCH

AVSD는 video-grounded multi-turn dialogue를 오래전부터 다뤘다. SVBench는 1,353개 streaming video의 49,979 temporal multi-turn QA를 제공한다. MuCo는 한 image의 여러 query-target pair를 한 forward pass에서 학습한다. MetaCompress는 MT-VQA 및 MT-Video-MME transfer를 평가한다.

Multi-turn data를 사용하거나 visual input을 한 번 처리한다는 사실만으로는 contribution이 되지 않는다.

Systems-level reuseSERVING

Preble은 VideoQA를 포함한 shared-prefix workload를 scheduling한다. Kamera는 video frame을 포함한 multimodal KV를 위치와 순서가 바뀌어도 재사용하도록 복원한다.

속도 향상이 단순 prefix/KV reuse에서 나오면 learning contribution이 아니라 systems baseline과 비교해야 한다.

03 · CURRENT VERDICT

이전 Proposal 2의 세 버전은 그대로는 독립 논문 주장이 약하다.

DROP 01

Queryable token tree

VideoTree, QTS+, VideoRouter, MuKV가 hierarchy와 query-adaptive evidence selection을 강하게 점유한다.

DROP 02

Cache or reconsolidation

ReKV·FlexMem·WorldMM·M3-Agent·PMMC와 경계가 흐리다. 저장 구조의 이름만 바꾸는 것으로는 충분하지 않다.

DROP 03

Future-query coverage loss

MetaCompress가 unknown future prompts를 위한 learnable prompt-agnostic compression을 이미 제시한다. Proposal 1과도 겹친다.

RESIDUAL GAP TO TEST, NOT YET A CLAIM

Online sequence-level amortization. 기존 연구들이 query별 retrieval, fixed-size memory, multi-turn accuracy와 cache efficiency를 각각 다루는 반면, 미래 질문을 모르는 policy를 전체 query sequence를 아는 offline oracle과 비교하고, query order·relatedness·memory budget에 따른 cumulative evidence-acquisition regret를 직접 최소화하는 video formulation은 이번 조사에서 직접적인 대응 연구를 찾지 못했다. 이것이 Proposal 2로 남길 수 있는 가장 명확한 가설이다.

04 · CANDIDATE METHOD

Representation을 다시 만들지 않고, evidence acquisition을 online decision problem으로 학습한다.

P1, MetaCompress, StreamMem 또는 frozen dense encoder가 만든 video index를 입력으로 사용할 수 있다. 새 모듈은 token 자체를 발명하지 않고 현재 질문에 필요한 신규 evidence 비용을 결정한다. Cache는 contribution이 아니라 어떤 evidence를 이미 계산했는지 표시하는 ledger다.

ENCODE ONCEVideo evidence index EP1 / MetaCompress / StreamMem
→
TURN tqₜ + opened evidence Oₜ₋₁future queries hidden
→
ONLINE POLICYreuse · retrieve · refine · evictcost-aware evidence action
→
ANSWER + LEDGERaₜ, Oₜpay only for new evidence

Offline oracle는 Q₁…Qᴺ 전체를 미리 보고 공동 evidence plan을 만든다. Online policy는 현재와 과거 질문만 보고 행동한다. 두 정책의 누적 비용·정확도 차이가 핵심 측정값이다.

M1

Offline sequence oracle

GT evidence span과 전체 query sequence를 이용해 같은 accuracy를 만족하는 최소 evidence union을 구한다. 연구 목표가 아니라 학습 target과 가능한 상한이다.

M2

History-conditioned marginal value

각 candidate evidence가 현재 답의 risk를 얼마나 줄이는지, 이미 열린 evidence와 얼마나 중복되는지 함께 예측한다.

M3

Online policy learning

Oracle imitation으로 시작하고, 이후 offline RL로 accuracy reward와 신규 perception·memory·latency cost를 함께 최적화한다.

SEQUENCE OBJECTIVE

한 질문의 top-k가 아니라 sequence 전체의 새 evidence 비용을 최소화한다.

Oₜ = Policy(qₜ, history<t, Oₜ₋₁, budget)
Jonline = Σₜ [Lanswer(qₜ, Oₜ) + λ Cnew(Oₜ \ Oₜ₋₁) + μ Cmemory(Oₜ)]
Regret = Jonline − Joffline-oracle

05 · MOTIVATION-FIRST EXPERIMENTS

Method를 만들기 전에 query sequence가 실제로 새로운 연구 문제인지 검증한다.

E1 · WORKLOAD

Real sequential-query protocol

SVBench의 temporal QA chain과 OASIS SQA setting을 사용한다. Ego4D NLQ는 동일 clip의 independent queries로 보조 분석하되 conversation이라고 부르지 않는다.

E2 · OFFLINE UPPER BOUND

Sequence oracle gap

GT evidence가 있는 episode에서 independent top-k와 full-sequence minimum evidence union을 비교한다. gap이 작으면 amortization method를 만들 이유가 없다.

E3 · ORDER EFFECT

Relatedness and permutation

같은 query set의 순서를 바꾸고 related·diverse chain을 나눠 cumulative new tokens, TTFT, accuracy를 측정한다. 순서 효과가 없다면 online formulation도 약하다.

E4 · STRONG BASELINES

Reuse before learning

MetaCompress, StreamMem, ReKV/StreamKV/MuKV, OASIS와 dense prefix cache를 동일 reader·accuracy·memory budget에서 비교한다.

C1

Sequence-level formulation

Q=1 accuracy가 아니라 Q={1,2,4,8,16}에서 누적 visual compute와 average marginal cost를 정의한다.

C2

Offline-oracle reference

전체 query를 미리 아는 최적 plan과 미래를 모르는 online policy 사이의 accuracy-cost regret를 보고한다.

C3

History-aware acquisition

현재 query relevance뿐 아니라 이미 확보한 evidence의 coverage를 조건으로 신규 computation의 marginal value를 학습한다.

C4

Order and interference audit

query 순서, semantic relatedness, bounded memory eviction이 reuse와 오류 전파에 주는 영향을 분리한다.

THE DECISIVE FIGURE

06 · KILL TESTS

아래 중 하나라도 성립하면 Proposal 2를 독립 논문으로 밀지 않는다.

NO-GO 01

Oracle gap이 작다

전체 query sequence를 미리 알아도 independent retrieval보다 evidence를 거의 줄이지 못하면 multi-query amortization의 실질적 여지가 없다.

NO-GO 02

Existing cache is enough

ReKV·MuKV·OASIS 또는 dense prefix cache가 같은 accuracy에서 online policy와 비슷한 cumulative cost를 얻으면 새 method가 필요 없다.

NO-GO 03

Gain is exact overlap only

성능 이득이 동일 GT span을 반복 묻는 query에만 존재하면 일반 multi-query contribution이 아니라 workload artifact다.
