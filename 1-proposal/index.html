PROPOSAL 01 · BROAD REPRESENTATION PROBLEM

Predictive Anytime Video Encoder

질문을 아직 모르는 상태에서도 짧고 결정적인 사건을 잃지 않는 nested video representation을 만든다. output token 수뿐 아니라 encoder 안에서 실행되는 token과 depth까지 budget에 맞춰 실제로 줄인다.

PRIMARY AXISRepresentation
QUERY AT ENCODEUnavailable
MAIN METRICAccuracy / encoder FLOPs
ONE-SENTENCE CLAIM

미래 semantic state를 예측하기 어려운 event에만 더 많은 token과 encoder depth를 배정하면, 하나의 pretrained encoder가 임의의 budget에서 temporal understanding을 보존할 수 있다.

01 · THE PROBLEM

Understanding에서 중요한 정보와 reconstruction에서 비싼 정보는 같지 않다.

긴 영상 대부분은 반복적이지만 정답을 결정하는 사건은 짧을 수 있다. 평균 pixel error나 현재-frame similarity만 줄이면 그 한순간이 가장 먼저 사라질 가능성이 있다.

FAILURE SCENE

64초 중 0.5초의 상태 변화가 질문의 정답을 바꾼다.

appearance는 거의 같지만 컵이 비워지는 순간, 손의 방향 전환, 행동 순서 반전은 temporal QA에 결정적이다.

L1

Pixel fidelity ≠ answer sufficiency

texture를 잘 복원해도 state change와 causal order를 잃을 수 있다.

L2

질문을 미리 사용할 수 없다

query-aware selector와 달리 encoder는 미래의 다양한 downstream task에 재사용되어야 한다.

L3

Post-hoc pruning은 encoder를 싸게 만들지 않는다

dense ViT를 전부 실행한 뒤 token만 줄이면 LLM prefill은 줄지만 vision FLOPs는 그대로다.

L4

Linear prefix는 semantic hierarchy를 보장하지 않는다

token 순서가 scene gist → event transition → object state로 조직되어야 작은 budget의 의미가 명확해진다.

03 · METHOD

Predict, measure the residual, then spend compute only where belief is unresolved.

encoder는 모든 chunk에 cheap gist를 쓰고, 미래 latent를 충분히 설명하지 못하는 event와 region만 다음 stage로 보낸다. 각 stage의 residual token을 누적하면 Matryoshka representation이 된다.

04 · NO-SCRATCH RECIPE

가설을 싸게 검증한 뒤 필요한 부분만 연다.

PHASE A · PROXY

Frozen features

V-JEPA 2 또는 pretrained video ViT feature 위에서 3개 budget의 proxy tokens와 predictor만 학습한다.

PHASE B · ROUTING

Adapters + gates

causal adapter, register, stage gate를 열고 random-budget training과 cost regularization을 적용한다.

PHASE C · TEMPORAL

Last blocks / LoRA

order, direction, state-change에서 이득이 확인된 경우 마지막 encoder block과 LoRA만 미세조정한다.

PHASE D · VLM

Projector + SFT

encoder 가설을 먼저 고정한 뒤 동일 LLM과 projector로 downstream QA를 비교한다.

05 · EVIDENCE NEEDED

Oral-level claim은 평균 QA 점수가 아니라 Pareto frontier로 증명한다.

C1

Predictive rate–distortion

understanding용 token value를 multi-horizon future semantics로 다시 정의한다.

C2

Token–depth joint anytime encoder

한 weight로 output length와 내부 vision FLOPs를 함께 조절한다.

C3

Unknown-query temporal sufficiency

질문 없이 만든 작은 state가 unseen temporal tasks에도 재사용됨을 보인다.

C4

Real efficiency protocol

encoder FLOPs, TTFT, throughput, VRAM을 같은 hardware에서 보고한다.

06 · KILL TESTS

아래 셋 중 하나가 실패하면 claim을 즉시 줄인다.

NO-GO 01

Predictive target가 temporal task를 못 살린다

동일 token·FLOPs에서 DINO/current-frame distillation보다 order·direction·anticipation이 오르지 않으면 핵심 objective를 폐기한다.

NO-GO 02

Routing overhead가 이득을 먹는다

실측 latency가 fixed encoder보다 낮아지지 않으면 fine-grained gate를 stage-level exit로 단순화한다.

NO-GO 03

작은 budget이 rare event를 버린다

appearance는 유지되는데 brief event recall이 급락하면 uniform gist 대신 surprise anchor를 강제한다.
