PROPOSAL 03 · HIGH RISK, HIGH REWARD

Streaming Visual Latent Reasoning

영상을 저장만 해두고 질문 뒤에 reasoning을 시작하지 않는다. query가 오기 전부터 bounded visual world-state가 미래를 예측하고, 새 관측과 충돌하면 latent 안에서 belief를 반복 수정한다.

PRIMARY AXISLatent computation
QUERY DURING STREAMOptional / unseen
MAIN METRICGain per latent step
ONE-SENTENCE CLAIM

query-free streaming state에 weight-tied visual latent iterations를 수행하면, memory 크기나 feed-forward depth만 늘리는 것보다 적은 parameter와 bounded memory로 causal·state-change understanding을 개선할 수 있다.

01 · THE PROBLEM

기억을 많이 남기는 것과 그 기억 위에서 생각하는 것은 다른 연산이다.

streaming memory는 과거 evidence를 보존하지만, 그 evidence가 암시하는 hidden state와 미래 결과를 반복적으로 갱신하지는 않는다. 반대로 최신 latent reasoning은 대체로 query가 주어진 뒤 시작한다.

BELIEF REVISION SCENE

초기 관측은 A를 지지하지만, 늦게 들어온 짧은 증거가 결론을 B로 뒤집는다.

좋은 state는 과거를 더 저장하는 데서 멈추지 않고 “내 예측이 틀렸다”는 신호로 내부 belief를 수정해야 한다.

L1

Query-conditioned reasoning starts too late

질문을 받은 뒤 latent를 생성하면 stream 중간에 축적할 수 있었던 causal computation을 활용하지 못한다.

L2

Memory update ≠ iterative reasoning

frame을 compression·retrieval하는 것만으로는 동일 state 위에서 여러 번 inference하는 test-time compute가 생기지 않는다.

L3

More steps can be empty computation

latent iteration 수를 늘려도 정답이 오르지 않으면 reasoning이 아니라 weight-tied depth 반복일 뿐이다.

L4

Prediction without correction is not belief revision

future latent loss만 맞추고 새 evidence가 기존 state를 어떻게 뒤집는지 보이지 않으면 world-model claim이 약하다.

02 · PRIOR-WORK BOUNDARY

“Latent reasoning”이라는 이름만으로는 이미 늦다. 언제, 무엇 위에서, 왜 반복하는지가 novelty다.

WorkWhat it already solvesWhat remains for this proposal

VideoLatentarXiv 2026

표준 video QA triplet만으로 visual latent reasoning을 학습해 text CoT 없이 video question을 푼다.

query 전 causal world-state, streaming observation 사이의 recurrent prediction–correction은 중심 설정이 아니다.

DyLaRarXiv 2026-08

query-grounded perception latent 뒤 필요한 경우에만 reasoning latent를 동적으로 추가한다.

reasoning이 query 이후 시작하며, unseen query 이전의 belief 형성과 revision을 다루지 않는다.

Future-L1arXiv 2026

language decoding 중 future-frame-aligned visual latent span을 interleave해 event prediction을 개선한다.

bounded streaming state를 observation 사이에서 recurrent하게 유지·수정하는 문제와는 다르다.

ThinkStreamarXiv 2026

Watch–Think–Speak로 stream마다 reasoning trace를 갱신하고 이를 compressed memory로 사용한다.

중간 memory가 textual reasoning trace이며, pure visual latent recurrence와 matched-compute 검증이 남는다.

RD-VLA / Sequential recurrent reasoningarXiv·OpenReview 2025–2026

weight-tied latent iteration, adaptive stopping, slow observation 사이 fast recurrent loop의 가능성을 보인다.

pretrained video representation, unknown future query, temporal belief-revision benchmark를 한 설정에서 입증하지 않는다.

THE OPEN GAP

질문 없이 진행되는 causal visual pre-reasoning: bounded state가 observation 사이에서 미래 semantic latent를 반복 예측하고, 실제 새 evidence가 도착하면 prediction error로 기존 belief를 명시적으로 수정하며, latent step 수에 따라 unseen temporal reasoning이 scale하는가?

03 · METHOD

A slow visual stream outside, a fast recurrent thought loop inside.

새 clip은 frozen video encoder로 한 번만 본다. bounded state는 observe update 뒤 K번의 shared latent operator를 통과하며 미래 state를 상상하고 consistency를 검사한다. 다음 clip이 오면 예측 오차가 correction signal이 된다.

Query adapter는 마지막 state를 읽기만 한다. core pre-reasoning path에는 language query나 textual CoT를 넣지 않는다.

M1

Bounded visual world-state

gist, event, object-state slots를 고정된 token budget으로 유지하고 새 observation은 surprise와 predicted relevance로 write한다.

M2

Weight-tied fast reasoning loop

동일 latent operator를 K번 반복해 state 간 relation과 future hypothesis를 refine하며 random-K training으로 anytime depth를 만든다.

M3

Predict–correct asymmetry

prior state는 미래 teacher latent를 예측하고, 다음 관측을 본 posterior state는 contradiction target으로 prior belief를 수정한다.

TRAINING OBJECTIVE

더 오래 생각할수록 prediction과 downstream belief가 함께 좋아져야 한다.

04 · EVIDENCE STANDARD

작은 run은 배관만 검사한다. 가설은 정식 benchmark가 판정한다.

작은 subset과 frozen image feature는 코드·metric·step curve가 정상인지 확인하는 smoke test다. 성공·실패 결론은 official split 전체와 strong video backbone, matched compute, 3 seeds에서만 내린다.

SMOKE TEST · NOT EVIDENCE

작은 run으로 연구 가능성을 판정하지 않는다.

05 · PAPER-GRADE STUDY

Pretrained video model과 공식 split으로 핵심 가설을 직접 검증한다.

PHASE A · CONTROL

Frozen video latent

EK100 official split과 video-native teacher로 recurrent head·halting의 인과 효과를 3 seeds에서 분리한다.

PHASE B · PREDICT

V-JEPA teacher

multi-horizon future latent와 state-change label을 사용해 query-free prior와 posterior correction을 학습한다.

PHASE C · ADAPT

LoRA / last blocks

adapter와 마지막 video block을 열어 visual state가 recurrence에 맞는 sufficient statistic이 되게 한다.

PHASE D · QA

Frozen reader

같은 query head에서 causal QA, anticipation, counterfactual을 평가해 core state의 이득을 분리한다.

06 · EVIDENCE NEEDED

좋은 결과는 “K번 돌렸다”가 아니라 K가 필요한 이유를 보여준다.

C1

Query-free causal pre-reasoning

language query 이전부터 visual state가 future hypothesis를 계산하는 새로운 video setting.

C2

Predict–correct recurrent state

prediction error가 새 observation에서 explicit belief revision으로 이어지는 학습 구조.

C3

Anytime latent compute

random-K와 convergence halting으로 memory를 늘리지 않고 reasoning depth를 동적으로 조절.

C4

Reasoning-vs-memory diagnostics

recurrence, feed-forward depth, memory size, text CoT를 matched FLOPs로 분리하는 평가 protocol.

07 · KILL TESTS

이 주제는 빠르게 죽일 수 있어야 안전하게 크게 시도할 수 있다.

NO-GO 01

K가 늘어도 성능이 오르지 않는다

random-K·intermediate loss 후에도 curve가 평평하면 latent reasoning claim을 중단한다.

NO-GO 02

Unshared depth가 항상 더 낫다

matched FLOPs·parameter 조건에서 recurrence의 extrapolation이나 efficiency 이득이 없으면 단순 deeper head다.

NO-GO 03

Belief가 새 증거로 수정되지 않는다

controlled contradiction에서 prior confidence만 유지하면 prediction loss를 posterior correction objective로 재설계한다.
