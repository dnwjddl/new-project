PROPOSAL 01 · BROAD REPRESENTATION PROBLEM

Adaptive Persistence–Innovation Video Encoder

모든 video를 같은 길이로 압축하지 않는다. 최소 semantic persistence–innovation pair에서 시작해, query 없이 다음 pair가 줄 semantic-temporal uncertainty를 판단하며 필요한 video에만 token을 추가한다. 최종 token budget은 미리 고르는 값이 아니라 이 progressive stopping 과정의 결과다.

01 · THE PROBLEM

Video에서 “coarse”가 무엇인지 정의하지 않으면 첫 token의 역할도 알 수 없다.

image에서는 layout→object→texture가 자연스러운 해상도 축이다. 그러나 video에서 coarse token이 평균 frame인지, 주행동인지, motion인지, 긴 시간의 요약인지는 서로 다른 주장이다. 먼저 기존 token의 실제 역할을 측정하고, 시간축에 고유한 persistence–innovation 분해를 학습 목표로 준다.

FAILURE SCENE

64초 중 0.5초의 상태 변화가 질문의 정답을 바꾼다.

appearance는 거의 같지만 컵이 비워지는 순간, 손의 방향 전환, 행동 순서 반전은 temporal QA에 결정적이다.

L1

Pixel fidelity ≠ answer sufficiency

texture를 잘 복원해도 state change와 causal order를 잃을 수 있다.

L2

질문을 미리 사용할 수 없다

query-aware selector와 달리 encoder는 미래의 다양한 downstream task에 재사용되어야 한다.

L3

Post-hoc pruning은 encoder를 싸게 만들지 않는다

dense ViT를 전부 실행한 뒤 token만 줄이면 LLM prefill은 줄지만 vision FLOPs는 그대로다.

L4

앞 token이라고 자동으로 “coarse”해지지 않는다

nested dropout은 prefix validity를 유도하지만, 각 token이 state·motion·order·rare event 중 무엇을 담당하는지 보장하지 않는다.

THE OPEN GAP

“Not coarse-to-fine, but persistence + innovation.” 최소 pair가 무엇이 유지되고 무엇이 변했는지를 함께 표현해 semantic-temporal gist가 된다. 이후 pair는 앞 prefix가 설명하지 못한 의미만 보충하고, 자동 모드는 다음 pair의 marginal semantic-temporal value가 계산 비용보다 작아지는 순간 멈춘다.

03 · VIDEO-NATIVE TOKEN ROLES

최소 persistence–innovation pair의 결합 자체가 semantic-temporal gist다.

Persistence는 계속 유지되는 객체·관계·상황을, innovation은 새 행동·상태 변화·사건 순서를 담는다. 둘 중 하나만으로는 video meaning이 불완전하므로 모든 budget tier에서 두 역할을 함께 추가한다. 별도의 gist token을 두지 않고 첫 pair의 결합을 최소 충분 video representation으로 학습한다.

WHAT “ORACLE K*” MEANS

한 video를 K={4,8,16,32}에서 모두 평가한 뒤, 여러 semantic-temporal question에서 full-budget 성능을 허용 오차 안에 유지하는 최소 K를 K*로 기록한다. K*는 모든 결과를 사후에 본 분석용 정답이므로 inference에는 쓰지 않는다. 대신 video마다 필요한 token 수가 실제로 다른지, 그리고 motion·scene cut·state change·event density·uncertainty 중 무엇이 K*를 가장 잘 설명하는지 밝힌다.

04 · METHOD

최소 pair에서 시작하고, 필요한 만큼만 다음 pair를 활성화한다.

얕은 shared feature에서 첫 persistence–innovation pair를 만들고, 아직 설명되지 않은 semantic-temporal information이 충분할 때만 다음 pair를 활성화한다. 선택된 token만 비싼 encoder block으로 보내므로 token output뿐 아니라 실제 vision encoder FLOPs도 video별로 달라진다.

Automatic mode는 최종 K를 먼저 분류하지 않는다. 최소 pair에서 출발해 다음 pair의 예상 가치가 비용보다 큰 동안만 반복한다. 모든 mode는 동일한 prefix Rₖ={(P₁,I₁),…,(Pₖ,Iₖ)}를 반환한다.

MODE A · USER-SPECIFIED

Hard budget execution

K = Kuser

사용자가 token 수, latency tier 또는 device profile을 지정한다. encoder는 정확히 K번째 pair tier까지만 활성화해 예측 가능한 FLOPs와 output length를 보장한다.

MODE B · BUDGET-FREE

Progressive marginal-value stopping

stop if Δ̂k+1 < λ · ΔCk+1

query 없이 다음 pair가 줄 semantic-temporal risk와 추가 FLOPs를 매 단계 비교한다. 최종 K는 이 반복 과정에서 video별로 결정된다.

SHARED INVARIANT

같은 video의 automatic output은 반드시 fixed-budget prefix 중 하나여야 한다. 별도 router representation을 만들지 않아 manual/automatic 결과를 직접 비교할 수 있다.

M1

Shared shallow feature

pretrained encoder의 stem과 얕은 temporal block만 모든 video에 실행한다. progressive token selection을 여기서 끝낸 뒤 선택된 prefix만 비싼 deep blocks로 보낸다.

M2

Persistence–innovation residual pairs

첫 pair는 최소 gist이며, k번째 추가 pair는 이전 prefix가 놓친 stable semantics, order, transition, rare event만 보충한다.

M3

Progressive value head

현재 prefix와 shallow feature만 보고 다음 pair가 줄 risk Δ̂V와 비용 ΔC를 예측한다. exact K를 미리 맞히지 않고 continue/stop을 반복한다.

DUAL-CONTROL TRAINING OBJECTIVE

모든 prefix를 유효하게 만들고, 다음 pair의 실제 semantic-temporal gain을 예측한다.

Lrisk(k) = Lsemantic(k) + Lorder(k) + Lchange(k) + Lfuture(k)
ΔV*k+1 = sg([Lrisk(k) − Lrisk(k+1)]+)
Lgate = SmoothL1(Δ̂Vk+1, ΔV*k+1) + Lcalibration
Ltotal = Σk wk Lrisk(k) + βLpair + γLgate + λE[FLOPs]
IS V-JEPA REQUIRED?

No. 가장 간단한 시작은 같은 model의 full-budget EMA branch를 self-target으로 쓰는 것이다. V-JEPA는 future-sensitive semantic target을 더할 수 있는 선택사항이다. 외부 teacher 없이도 action·order·state-change·future losses에서 계산한 prefix별 error 감소가 gate의 analysis target이 된다.

05 · NO-SCRATCH RECIPE

Frozen backbone에서 pair roles를 만든 뒤 progressive gate를 연결한다.

처음부터 backbone 전체와 discrete gate를 함께 학습하면 representation과 routing이 동시에 흔들린다. 먼저 최소 pair가 gist가 되도록 persistence·innovation role을 학습하고, 다음 pair의 실제 utility를 예측한 뒤, 마지막에만 encoder adapter를 열어 FLOPs–accuracy Pareto를 조정한다.

PHASE A · K* ANALYSIS

Measure every token tier

각 video를 K={4,8,16,32}에서 평가해 minimum sufficient K*와 인접 tier의 실제 risk 감소 ΔV*를 만든다. 이 단계는 분석용이며 inference 방식이 아니다.

PHASE B · FROZEN ROLE LEARNING

Learn the minimum gist pair

backbone은 freeze하고 P/I registers와 projection heads만 학습한다. semantic-preserving pair에는 같은 gist를, temporal counterfactual pair에는 다른 innovation을 요구한다.

PHASE C · PROGRESSIVE GATE

Predict one next pair at a time

현재 prefix와 shallow feature에서 다음 pair의 Δ̂V를 회귀한다. one-shot K classifier가 아니라 continue/stop을 반복하고 calibration error와 stopping regret를 측정한다.

PHASE D · JOINT EFFICIENCY

Open adapters, then LoRA

먼저 tokenizer와 deep-block adapter를 열고 마지막에 backbone의 뒤 2–4 block LoRA를 연다. expected FLOPs penalty로 항상 full budget을 쓰는 해를 막는다.

RECOMMENDED FIRST MODEL

Pretrained causal video backbone + shared shallow feature + four nested P/I token tiers + progressive value head. Phase B까지 backbone을 freeze하고, 선택된 prefix만 deep blocks로 보낸다. 이 구성이 성공한 뒤에만 last-block LoRA를 사용하면 scratch training 없이 representation gain과 compute gain을 분리해 분석할 수 있다.

06 · EVIDENCE NEEDED

방법을 키우기 전에 세 개의 paper-grade 실험으로 전제를 확인한다.

E1 · DONE

Equal-budget failure audit

5개 압축 규칙을 동일 K와 common public backbone에서 비교했다. 일반 accuracy와 changed-answer counterfactual family의 answer-flip 순위가 달랐고, low-budget representation의 temporal loss가 aggregate score에 숨는 현상을 확인했다.

E2

K* determinant analysis

모든 K를 사후 평가해 video별 minimum sufficient K*를 얻고, motion-only predictor와 semantic change·event density·uncertainty predictor가 K*를 얼마나 설명하는지 held-out split에서 비교한다.

E3

Automatic-budget feasibility

shallow feature만 보는 progressive gate를 fixed K, motion heuristic, random allocation, one-shot K classifier, analysis-only oracle과 동일 평균 FLOPs에서 비교한다.

DECISIVE RESULT

더 많은 token이 QA는 개선하면서 temporal sensitivity는 악화시킬 수 있다. Contiguous pooling의 K=32는 K=8보다 QA가 +1.84pp 높았지만(p=0.006), answer-flip은 -2.24pp 낮았다(p=0.049). Uniform sampling의 K=4→32 추가 정답 103개 중 82개(79.6%)가 action subset에서 나왔고 order gain은 0개였다. 따라서 temporal gist는 token 수나 aggregate accuracy가 아니라 별도 학습 목표로 정의해야 한다.

NATIVE-SCALE REFERENCE

EarlyTom의 원래 0.10 retain ratio는 video당 631-633 tokens를 사용해 QA 52.34, strict family 5.99, answer-flip 24.69를 기록했다. K=32 cap보다 QA는 +9.18pp 높았지만 answer-flip은 사실상 같았다(-0.25pp, p=1.0). 이 결과는 released method가 정상 규모에서는 작동한다는 기준점이며, 위 표의 K=4-32는 temporal evidence가 무너지는 extreme-budget 영역을 별도로 검증한다.

GO / NO-GO BEFORE THE FULL METHOD

진행 조건은 (1) video별 K* 분산이 충분히 크고, (2) semantic-temporal factor가 raw motion보다 K*를 잘 예측하며, (3) progressive gate가 같은 평균 token의 fixed K보다 높은 paired understanding score를 내는 것이다. 이 셋이 성립한 뒤 P/I role learning을 full scale로 확장한다.

C1

Video token role audit

“앞 token=coarse”라는 통념을 persistence·innovation·order·rare-event intervention으로 정량 검증한다.

C2

Persistence–innovation gist

별도 coarse token 없이 최소 P/I pair의 결합을 semantic-temporal gist로 정의하고 이후 pair가 residual meaning만 보충하게 한다.

C3

Progressive marginal value

다음 pair가 줄 semantic·order·state-change·future risk를 실행 전에 예측해 exact K를 선결정하지 않고 자동으로 멈춘다.

C4

Real encoder efficiency

output pruning이 아니라 skipped block을 포함한 encoder FLOPs, latency, throughput, VRAM과 stopping regret를 보고한다.

07 · KILL TESTS

아래 셋 중 하나가 실패하면 role-aware claim을 즉시 줄인다.

NO-GO 01

Token은 줄지만 encoder FLOPs는 그대로다

초기 dense stage가 전체 계산을 지배하거나 conditional block의 실제 latency가 줄지 않으면 efficient encoder가 아니라 output compressor로 claim을 낮춘다.

NO-GO 02

Automatic gate가 fixed K를 이기지 못한다

동일 평균 GFLOPs에서 accuracy gain이 없거나 K* 대비 stopping regret가 크면 automatic allocation claim을 축소한다.

NO-GO 03

P/I role이 downstream gain으로 연결되지 않는다

같은 token·FLOPs의 direct distillation과 order·state-change benchmark 차이가 없으면 persistence–innovation objective의 claim을 축소한다.

RTX 3090 최적 batch는 12였고 0.477 clip/s, peak reserved memory 17.95 GiB였다. 모든 3,568 action stratum을 포함한 deterministic train 16k와 decodable val 9,657개를 8개 GPU로 처리했으며 slowest shard는 train 52.4분, val 43.6분이었다. 3-seed concatenated·fixed-dimension probe 전체 분석은 RTX 4090 한 장에서 8분 23초였다.

FULL-SPLIT RESULT · EK100 · 3 SEEDS

통상적인 action probe는 시간 순서에 거의 둔감했다. ViCLIP-L/14 frozen feature의 ordered action top-1은 15.02%였지만 reverse는 14.60%(-0.42pp), shuffle은 14.62%(-0.40pp)였다. 반면 한 frame만 반복한 single 조건은 10.24%(-4.78pp)까지 하락했다. 즉 이 probe는 appearance·object 제거에는 반응하지만 순서 교란은 거의 구별하지 못한다. 공식 train 67,217개와 val 9,668개를 사용했고, 손상된 원본 video packet 때문에 train 1개와 val 9개 segment만 동일 규칙으로 제외했다.

PILOT VERDICT

기존 순서는 understanding의 successively refinable coarse-to-fine이 아니다. Quantized concatenated probe에서 첫 8-token prefix의 action top-1은 4.10%로 256-token의 3.35%보다 높았다. 입력 차원을 모두 18로 맞춘 통제에서도 8-token prefix는 2.77±0.14%, 256-token은 1.83±0.09%였고, 첫 block은 2.69%로 이후 block의 1.15–1.63%보다 강했다. 첫 block은 reverse에도 더 민감해 action과 order 정보가 앞쪽에 섞여 몰려 있었다. 따라서 우리의 목표는 “앞=coarse”를 반복하는 것이 아니라 semantic persistence와 order-sensitive innovation을 명시적으로 분리하고, 추가 pair가 남은 semantic residual을 단조롭게 줄이게 만드는 것이다.
