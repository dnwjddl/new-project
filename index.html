RESEARCH BRIEF · LITERATURE SWEEP THROUGH 2026-08-08

One Video, Any Budget

목표는 token 수만 줄이는 compressor가 아니다. 영상의 미래를 이해하는 데 충분한 상태를 만들고, budget이 허용하는 만큼만 encoder 계산과 표현을 점진적으로 확장하는 video encoder다.

핵심 thesis

영상이 요구하는 token 수는 pixel complexity가 아니라 아직 해소되지 않은 predictive uncertainty로 결정되어야 한다.

01 · RESEARCH VERDICT

세 아이디어는 좋다. 다만 그대로는 두 개가 이미 붐비는 영역이다.

VideoFlexTok은 이미 time-causal encoder, nested dropout, DINOv2 REPA, streaming tokenization을 generation 축에서 제시했다. Query-aware hierarchy와 streaming memory도 2025–2026년에 강한 경쟁작이 빠르게 생겼다. 아래처럼 novelty의 중심을 이동시키는 것이 안전하다.

Predictive rate–distortion

NO-SCRATCH RECIPE

현실적인 학습 순서

  1. V-JEPA 2를 frozen teacher로 두고 pretrained video ViT student를 초기화한다.
  2. register/proxy tokens, causal adapters, predictor, budget router만 먼저 학습한다.
  3. 가능성이 확인되면 student 마지막 block과 LoRA를 점진적으로 연다.
  4. LLM 연결은 encoder 가설이 검증된 뒤 projector/SFT 단계로 분리한다.

FOUR FALSIFIABLE HYPOTHESES

논문이 반드시 증명해야 할 것

  1. 한 모델의 모든 budget이 budget별 전용 모델에 근접한다.
  2. predictive objective가 DINO/reconstruction보다 temporal reasoning을 잘 보존한다.
  3. in-encoder routing이 post-hoc pruning보다 실제 TTFT와 GFLOPs를 줄인다.
  4. router가 oracle budget과의 간격을 의미 있게 좁힌다.

03 · THREE TOPICS, REBUILT

각 아이디어를 논문 단위로 구체화하면

탭을 눌러 각 안의 실제 novelty, 학습 방식, 결정적 실험과 중단 기준을 비교할 수 있다.

TOPIC 01 · PRIMARY

Temporal reasoning을 보존하는 실제 dynamic encoder

VideoFlexTok의 “generation을 understanding으로 바꾼다”만으로는 약하다. time-causal과 streaming도 이미 들어 있다. novelty는 future-semantic sufficiency + internal conditional compute다.

Method

  • 시점별 gist register를 shallow block에서 생성
  • predictive residual이 큰 event/region만 deeper block으로 전달
  • 각 depth의 residual token을 합치면 nested representation 형성
  • V-JEPA 2 teacher의 현재 및 미래 latent를 여러 horizon에서 distill
  • budget-conditioned stochastic training으로 하나의 weight 유지

Decisive experiment

같은 output token 수와 같은 encoder GFLOPs에서 reconstruction/DINO teacher 대비 TempCompass의 direction·order, Something-Something v2, action anticipation을 동시에 개선해야 한다.

Kill criterion

frozen proxy가 full V-JEPA feature의 temporal score를 보존하지 못하거나, routing overhead를 포함한 latency가 fixed encoder 대비 줄지 않으면 구조를 축소한다.

TOPIC 02 · SECOND PAPER CANDIDATE

한 번 저장하고, 질문마다 필요한 가지에서만 detail을 연다

VideoTree는 query를 보며 tree를 만들고, QTS+/VideoRouter는 flat dense tokens에서 query-relevant evidence를 고른다. 우리는 query 전에 만든 persistent latent tree를 여러 질문이 공유한다.

Method

  • scene/event boundary에 맞춘 temporal latent tree를 query 없이 생성
  • parent token은 summary, child token은 parent가 잃은 predictive residual로 학습
  • query router가 top-down beam으로 branch와 depth를 budget 안에서 결정
  • global gist를 항상 남겨 잘못된 early routing의 복구 경로 제공
  • 동일 영상에 연속 query가 들어오는 multi-query cost를 직접 평가

Decisive experiment

query 1개가 아니라 5·10·20개가 같은 영상에 순차적으로 들어올 때, VideoTree/QTS+/flat top-k보다 total encoder+retrieval latency와 accuracy의 Pareto frontier가 좋아야 한다.

Kill criterion

동일 total token budget에서 learned tree가 flat top-k를 이기지 못하거나, 초반 branch miss가 answer-critical evidence를 반복적으로 제거하면 독립 논문 대신 flagship의 optional readout으로 낮춘다.

TOPIC 03 · HIGH RISK

기억의 가치는 “다시 보기 어려움”이 아니라 “미래를 바꾸는 정도”다

recent streaming methods도 surprise, semantic salience, object anchor를 사용한다. 차별점은 token을 제거했을 때 multi-horizon future prediction이 얼마나 악화되는지를 memory utility로 학습하는 것이다.

t−3t−2t−1t→future
always retained
evict low Δprediction-loss
memory state predicts future teacher latents

Method

  • 모든 chunk는 tiny gist를 write하고 필요할 때 residual tier 추가
  • token utility를 leave-one-out future latent loss 증가량으로 정의
  • 비싼 counterfactual score를 작은 eviction policy에 distill
  • 오래된 sibling residual은 상위 gist로 consolidate
  • query는 write가 아니라 read 시점에만 memory scope를 선택

Decisive experiment

OVO-Bench의 backward tracing과 forward active response에서 동일 고정 memory로 SimpleStream, StreamMem, CausalMem보다 좋아야 하며 current-scene perception을 희생하지 않아야 한다.

Kill criterion

강한 recent-window baseline을 넘지 못하거나, future prediction utility와 unseen-query QA utility의 상관이 낮으면 “latent reasoning” 주장은 버리고 memory analysis로 범위를 줄인다.

04 · NOVELTY BOUNDARY

VideoFlexTok과 무엇이 정확히 다른가

축VideoFlexTok제안하는 flagship검증 포인트
Primary goal generation용 flexible tokenizer understanding용 anytime encoder temporal reasoning / anticipation
Training signal flow reconstruction + DINOv2 REPA multi-horizon V-JEPA latent prediction predictive sufficiency at every prefix
Budget structure tail prefix over per-frame registers gist + learned event/region residuals non-linear, content-adaptive refinement
Encoder compute token output length 중심 active tokens와 depth를 함께 조절 encoder GFLOPs / latency 포함
Streaming sliding-window encode, decoded-frame conditioning causal latent state 자체를 계속 갱신 bounded state, unknown future query

time-causal attention과 “streaming 가능” 자체는 novelty로 주장하지 않는다. 두 요소는 VideoFlexTok이 이미 명시적으로 보여준다.

THE OPEN SPACE

아직 명확히 비어 있는 조합

predictive semantics로 학습된 nested representation과 encoder 내부의 anytime compute, 그리고 unknown-query streaming sufficiency를 하나의 평가 축으로 묶은 연구는 위의 가장 가까운 연구들과 구별된다. 이것이 현재 proposal에서 가장 방어하기 좋은 중심이다.

BOTTOM LINE

세 편을 동시에 시작하지 않는다.

먼저 flagship의 가장 작은 실험으로 future-predictive token hierarchy가 정말 temporal reasoning을 더 잘 보존하는지 확인한다. 성공하면 query tree는 재사용 가능한 readout으로, memory codec은 streaming extension으로 자연스럽게 확장된다. 실패하면 큰 학습 전에 가설을 버릴 수 있다.
